# 变式出卷 Skill（bianshi）

## 功能说明

本 Skill 为变式试卷生成助手提供规则约束，支持两种输入模式：
- **图片模式**：输入为一张或多张试卷图片（多张视为同一份试卷的不同页）
- **文本模式**：输入为已有试卷的结构化文本

两种模式的**变式规则和输出格式完全相同**，仅第一步（识别原卷内容）不同。

---

## 变式工作流程（按顺序执行，不可跳步）

### 第一步：获取原卷内容

**图片模式**：
1. 从图片中逐题提取题型、题干、选项（若有）
2. 识别大题分组结构（如「一、选择题」「二、填空题」）
3. 图片中的答案和解析仅供参考，变式题必须重新生成
4. 若图片无法识别到任何有效题目，停止生成并返回提示「未能从图片中识别到有效题目」

**文本模式**：
1. 直接从文本中读取题型、题干、选项
2. 大题分组结构以原文本中的分组为准

### 第二步：加载数学公式规范（数学题时）

若原卷含数学题，加载 `references/output-format.md`，查阅 LaTeX 公式写法规范（禁用 Unicode 符号、填空线写法等）。

### 第三步：配图决策（仅数学题，逐题在写变式题干之前完成）

语文、英语题跳过此步骤，`diagrams` 字段始终为 null。

每道数学变式题在写题干之前，先做二选一判断：

**→ 选择「配图模式」的条件（满足任一即选此模式）**：
- 多点空间位置关系（需辅助线，如高线、中线、角平分线）
- 图形变换（折叠、旋转、翻折）
- 多边形与圆的组合（切线、内接多边形）
- 需要学生在图上作图

**→ 选择「纯文字模式」的条件**：
- 边长、角度已用数字明确给出
- 平行线与截线关系
- 简单位置关系（M 是 AB 中点、点 D 在 BC 上等）

| 模式 | content 写法 | diagrams 字段 | 额外操作 |
|------|------------|---------------|---------|
| **配图模式** | 以"如图，…"起笔，引用图中标注 | 必须输出 TikZ 代码 | 加载 `references/geometry-tikz.md` |
| **纯文字模式** | 直接文字描述，**禁止出现"如图""下图"等词** | null | 无 |

> 禁止在 content 里写"如图"的同时把 diagrams 设为 null，不论加什么括号注释都不合法。

**diagrams 字段格式**（配图模式使用）：
```json
"diagrams": [
  {
    "sortOrder": 1,
    "tikzCode": "\\tkzDefPoint(0,0){A}\n..."
  }
]
```
- `tikzCode` 只含 `tikzpicture` 内的内容，后端自动包裹外层模板
- 禁止命令：`\input`、`\include`、`\write18`、`\immediate`、`\openout`、`\closeout`
- TikZ 命令写法详见 `references/geometry-tikz.md`

### 第四步：逐题生成变式

**变式核心原则（中度变式）**：

| 维度 | 规则 |
|------|------|
| **保持不变** | 题型（type 字段值）、考察知识点、题目难度级别 |
| **必须改变** | 情境背景、数据数值、问法表述 |
| **禁止** | 仅修改数字；仅换人名/地名 |

**变式示例**（数学填空题）：
- 原题：小明有苹果 24 个，分给 6 个小朋友，每人得 $\underline{\hspace{1cm}}$ 个。
- ✅ 变式：一列火车全程 360 千米，以每小时 60 千米的速度行驶，需要 $\underline{\hspace{1cm}}$ 小时。
- ❌ 错误变式：小明有苹果 36 个，分给 6 个小朋友，每人得 $\underline{\hspace{1cm}}$ 个。（只换了数字）

**选择题特殊规则**：
- 选项内容必须完全重新设计，不能复用原题选项
- 正确答案的位置（A/B/C/D）必须重新分配
- 4 个干扰项要有合理性，能考查易错点

**答案与解析要求**：
- 每道变式题必须提供完整的 `answer` 和 `explanation`，无论原题是否有答案
- `explanation` 须清晰说明解题思路和易错点，不可只给结果

### 第五步：组装整卷

- 保持原试卷的大题分组结构（section 数量和题型分组与原卷一致）
- 文本模式：大题标题与原卷完全一致
- 每个 section 的 `scoreNote` 格式：「每题 X 分，共 Y 分」
- 所有题目 score 之和必须等于 totalScore
- 试卷标题：原标题加「变式练习」，如「五年级数学期末卷」→「五年级数学变式练习卷」；无法识别标题时生成「变式练习卷」

## 提交规范

按顺序调用工具提交：
1. 先调用 `submit_variant_outline` 提交变式大纲（大题分组、题型、每题分值、总分）
2. 再逐题调用 `submit_variant_question` 提交每道变式题（参数为结构化对象）

题目参数包含 `type`、`content`、`options`、`answer`、`score`、`explanation`、`diagrams`、`blanks`、`subQuestions` 等，遵循下方规则填写。

**题型 key 对照表**：

| 中文题型名 | type 值 |
|-----------|--------|
| 单选题 | `choice` |
| 多选题 | `multi` |
| 判断题 | `judge` |
| 填空题 | `fill` |
| 简答题 | `short` |
| 应用题 | `apply` |
| 计算题 | `calculation` |
| 解答题 | `solution` |
| 阅读理解题 | `reading` |
| 写作题 | `writing` |
| 自定义题型 | `custom` |

**自定义题型字段**：
- type/questionType 使用 custom，名称填 customQuestionTypeName，定义填 customQuestionTypeDescription；已给出的名称、定义原文保留，缺失时留空，标准题型两字段为空。
- 父题、子题分别填写自身题型、名称和定义，不继承父题。
- 用当前输出结构中的题干、选项、子题等字段表达定义，不增加字段或答题控件。

**各题型 answer 格式**：
- `choice`：`["A"]`
- `multi`：`["A", "C"]`（字母顺序）
- `judge`：`["TRUE"]` 或 `["FALSE"]`；必须提供 options；题干末尾加 `（　　）`（两个全角空格）
- `fill` 单空：`["答案"]`；多空：`["答案1", "答案2"]`；填空线用 `$\underline{\hspace{2cm}}$`
- `apply`：`["分步过程...\n答：..."]`
- `calculation`：`["分步计算过程...", "最终答案"]`
- `solution`：`["分步解答过程...", "结论"]`
- `reading`：content 仅放阅读材料，各小题进 `subQuestions`
- `writing`：answer 为 `["参考范文或写作提纲"]`
- `short`：answer 为 `["要点一", "要点二"]`

### 整卷结构

整卷的标题、总分、建议时长与各大题分组通过 `submit_variant_outline` 提交，由后端组装，无需单独输出整卷 JSON。

## 生成后自查清单

每道变式题生成完成后必查：

- [ ] **题型**：变式题 type 与原题完全相同？
- [ ] **变式质量**：不是仅换数字或人名？情境/问法有实质变化？
- [ ] **配图（数学）**：配图模式 → diagrams 有 TikZ 代码？纯文字模式 → content 没有"如图"类词语？
- [ ] **答案**：每道变式题都有完整的 answer 和 explanation？
- [ ] **分值**：所有题目 score 之和 = totalScore？
- [ ] **选择题**：选项和正确答案位置完全重新设计？
