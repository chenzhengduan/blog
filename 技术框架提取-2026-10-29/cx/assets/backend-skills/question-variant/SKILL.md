# 单题变式 Skill（question-variant）

## 功能说明

本 Skill 为单题变式生成助手提供规则约束。与整卷变式（bianshi）不同，本 Skill 专注于
**单道题目**的变式生成，且需要在缺失题型时进行推断。

---

## 变式工作流程（按顺序执行，不可跳步）

### 第一步：理解原题

1. 从请求中读取原题题干、选项、答案、解析、TikZ 配图和图片（若有）
2. 若有图片，结合图片理解原题中的视觉信息（几何图、插图、截图等）
3. 若原题答案未提供，先自行理解原题考点和解题路径，再继续生成变式
4. 若原题信息不足以理解考点，停止生成并返回提示「无法从原题可靠识别考查内容」

### 第二步：推断题型（仅在元数据未提供时）

- **题型（questionType）**：根据原题结构推断 choice / fill / short 等

原题不属于标准题型时使用 custom；名称仅从原题明确给出的题型名提取，名称不明时留空，不编造定义。

### 第三步：加载知识范围和输出格式

1. 使用 load_skill_through_path 加载 `SKILL.md`（本文件）
2. 若学科为数学，加载 `references/output-format.md` 查阅 LaTeX 公式规范
3. 若新题需要几何配图，加载 `references/geometry-tikz.md` 查阅 TikZ 命令写法

### 第四步：配图决策（仅数学题，在写变式题干之前完成）

语文、英语题跳过此步骤，`diagrams` 字段始终为 null。

每道数学变式题在写题干之前，先做二选一判断：

**→ 选择「配图模式」的条件（满足任一即选此模式）**：
- 多点空间位置关系（需辅助线，如高线、中线、角平分线）
- 图形变换（折叠、旋转、翻折）
- 多边形与圆的组合（切线、内接多边形）

**→ 选择「纯文字模式」的条件**：
- 边长、角度已用数字明确给出
- 简单位置关系（M 是 AB 中点、点 D 在 BC 上等）

| 模式 | content 写法 | diagrams 字段 | 额外操作 |
|------|------------|---------------|---------|
| **配图模式** | 以"如图，…"起笔 | 必须输出 TikZ 代码 | 加载 `references/geometry-tikz.md` |
| **纯文字模式** | 直接文字描述，禁止"如图""下图" | null | 无 |

### 第五步：生成变式题

**变式核心原则（中度变式）**：

| 维度 | 规则 |
|------|------|
| **保持不变** | 题型、考察知识点、题目难度级别 |
| **必须改变** | 情境背景、数据数值、问法表述 |
| **禁止** | 仅修改数字；仅换人名/地名；直接复制原题题干/选项/答案/解析 |

**选择题特殊规则**：
- 选项内容必须完全重新设计，不能复用原题选项
- 正确答案的位置（A/B/C/D）必须重新分配
- 4 个干扰项要有合理性，能考查易错点

**答案与解析要求**：
- 变式题必须提供完整的 `answer` 和 `explanation`，无论原题是否有答案
- `explanation` 须清晰说明解题思路和易错点，不可只给结果

**图片处理规则**：
- 输入图片仅作为理解原题的上下文，不要求输出复用输入图片
- 不生成普通插画图片，输出视觉仅限 TikZ 几何配图
- 若原题图片是普通插画，尽量将图中信息转为文字条件生成不依赖图片的新题

**完成变式题后，调用 `submit_variant_question` 一次性提交（见下方「提交规范」）。**

## 提交规范

生成变式题后，必须调用 `submit_variant_question` 工具一次性提交，参数为结构化对象，提交成功即任务完成。参数中的字段 `questionType`、`type`、`content`、`options`、`answer`、`explanation`、`diagrams`、`blanks`、`subQuestions`、`difficulty` 遵循下方规则填写。

> 注：`source` 字段由后端自动设置，无需 AI 输出。

questionType 与 type 填写相同的题型编码。

**题型 key 对照表**：

| 中文题型名 | type 值 |
|-----------|--------|
| 单选题 | `choice` |
| 多选题 | `multi` |
| 判断题 | `judge` |
| 填空题 | `fill` |
| 简答题 | `short` |
| 应用题 | `apply` |
| 计算题 | `calculation` |
| 解答题 | `solution` |
| 阅读理解题 | `reading` |
| 写作题 | `writing` |
| 自定义题型 | `custom` |

**自定义题型字段**：
- type/questionType 使用 custom，名称填 customQuestionTypeName，定义填 customQuestionTypeDescription；已给出的名称、定义原文保留，缺失时留空，标准题型两字段为空。
- 父题、子题分别填写自身题型、名称和定义，不继承父题。
- 用当前输出结构中的题干、选项、子题等字段表达定义，不增加字段或答题控件。

**各题型 answer 格式**：
- `choice`：`["A"]`
- `multi`：`["A", "C"]`（字母顺序）
- `judge`：`["TRUE"]` 或 `["FALSE"]`
- `fill` 单空：`["答案"]`；多空：`["答案1", "答案2"]`
- `apply`/`calculation`/`solution`：`["分步过程...\n答：..."]`
- `short`：`["要点一", "要点二"]`

## 生成后自查清单

- [ ] **题型**：变式题 type 与原题一致（或与推断题型一致）？
- [ ] **变式质量**：不是仅换数字或人名？情境/问法有实质变化？
- [ ] **答案**：有完整的 answer 和 explanation？
- [ ] **配图（数学）**：配图模式 → diagrams 有 TikZ 代码？纯文字模式 → content 没有"如图"类词语？
- [ ] **题型**：questionType 非空且合法（与原题一致或推断正确）？
- [ ] **非复制**：题干、选项、答案、解析均未直接复制原题？
