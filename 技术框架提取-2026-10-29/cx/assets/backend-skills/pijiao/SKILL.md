# 批改 Skill（pijiao）

## 功能说明

本 Skill 为中小学 AI 答卷批改助手提供评分规范，支持填空题、简答题、应用题、计算题、解答题、阅读理解题、写作题等主观题型。

---

## 批改核心原则

1. **以标准答案为基准**：参照题目的 `standard_answer` 字段进行评分，允许同义表达、等价写法。
2. **阶梯分**：对过程性题目（应用题、计算题、解答题），按解题步骤给步骤分；最终答案正确但过程缺失，只给答案分（不超过 50%）。
3. **分数范围**：`score` 必须为整数，取值范围 `[0, max_score]`，不得超出满分。
4. **feedback 要求**：简洁、具有建设性，指出失分原因或值得肯定之处，不超过 100 字。
5. **严格不超分**：任何情况下 `score` 不得超过 `max_score`。

---

## 各题型评分指引

### fill（填空题）

- 关键词匹配优先：与标准答案完全一致给满分。
- 同义词、合理等价表达可酌情给分（不超过满分）。
- 多空题：每空独立评分，最终汇总（汇总由调用方处理，此处按 LLM 能力返回整题分）。
- 完全错误或与知识点无关：0 分。

### short（简答题）

- 按要点覆盖度评分：列出标准答案的主要知识点，学生答案覆盖的要点比例乘以满分取整。
- 答出关键要点但表述不够完整：给 60%~80% 分值。
- 答案方向正确但内容笼统：给 30%~50% 分值。

### apply（应用题）

- 设定未知量（1 分）→ 建立方程/不等式（2 分）→ 解方程过程（2 分）→ 最终答案及单位（1 分），满分结构按实际分值等比分配。
- 步骤完整且答案正确：满分。
- 缺少单位或结论句：扣 10%~20%。
- 过程正确但计算出错：给过程分（约 60%~80%）。

### calculation（计算题）

- 分步计算：每步正确给对应步骤分。
- 最终结果正确但中间步骤有小错误：扣中间步骤分，保留结果分。
- 仅写出最终结果无过程：给 30%~50%。

### solution（解答题）

- 通用解答题，按解题完整性评分：
  - 分析/设定（20%）→ 推导过程（50%）→ 结论（30%）。
- 结论正确但证明过程有逻辑跳步：扣 20%~40%。

### reading（阅读理解题）

- 题目通常包含多个小题；按各小题逐一批改，累加后返回总分。
- 客观小题（选择、判断）：完全匹配才给分。
- 主观小题（简答）：参照 short 题型评分标准。
- 引用原文题：答案包含原文关键句给满分，意译酌情给分。

### writing（写作题）

- 四个维度综合评分：
  - 结构完整性（25%）：有开头、正文、结尾。
  - 内容切题度（30%）：主题明确，内容与题目要求吻合。
  - 语言流畅度（25%）：语句通顺，表达清晰，无明显病句。
  - 字数符合要求（20%）：字数在题目规定范围内（差距超 30% 扣分）。
- feedback 须具体说明各维度亮点或不足。

## 图片答案处理

若学生提交了手写答案图片，请按以下步骤处理：

1. **识别手写内容**：完整描述图片中的文字、公式、步骤，确保不遗漏关键信息。
2. **按题型批改**：将识别内容视为学生的文字答案，参照上述题型评分标准进行批改。
3. **图片不清晰**：若图片模糊无法识别，feedback 注明"图片不清晰，无法批改"，score=0。

---

## 空白答案处理

若学生的文字答案为空且无图片（或图片无内容），则：

- `score` = 0
- `feedback` = "未作答"

---

## 结构化输出格式

每道题必须以以下 JSON 格式输出，不得包含其他字段：

```json
{
  "score": 7,
  "feedback": "解题思路正确，步骤完整，但最后一步单位遗漏，扣 1 分。"
}
```

**字段说明**：

| 字段 | 类型 | 约束 |
|------|------|------|
| `score` | Integer | 必填，范围 [0, max_score]，不可超出满分 |
| `feedback` | String | 必填，简洁说明得分情况，不超过 100 字 |
