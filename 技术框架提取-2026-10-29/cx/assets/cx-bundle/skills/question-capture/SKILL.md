# 录题

本技能把图片或文档中的题目识别为可编辑草稿，并引导用户到 CX 复核页面确认入库。

适用场景：
- 用户上传一道或多道题目图片并要求录题。
- 用户上传 PDF、DOC 或 DOCX 练习材料并要求提取题目。
- 用户想查询刚创建的录题任务进度，或明确要求取消任务。

典型任务：
- 按附件顺序创建录题任务。
- 返回任务 ID 和复核链接。
- 查询识别题量、待复核题量和 AI 答案完成状态。

使用规则：
- 所有图片和文件都使用当前会话提供的 HTTPS URL，不传 Base64。
- 来源按用户附件顺序从 1 连续编号；图片使用 `image`，PDF/Word 使用 `document`。
- 最多一份文档；图片与文档展开后的标准页合计最多 20 页。
- MIME 类型必须与文件一致：图片使用实际 image MIME；PDF 使用 application/pdf；Word 使用对应 DOC/DOCX MIME。
- 创建成功后立即向用户展示任务 ID和复核链接，说明后台仍在识别，可打开链接查看进度。
- 复核链接是权威操作入口；不要把完整题目草稿、答案、坐标或签名 URL 复述到对话中。
- 只有用户明确说停止或取消时才能取消进行中的任务。

边界与限制：
- 创建任务不会自动把所有草稿确认进正式题库；用户需在复核页面检查、修改、裁图并确认。
- 不要替用户自动确认低置信度题目或需要人工复核的题目。
- 本技能不负责整卷变式或单题变式。
