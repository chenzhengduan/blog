## 核心思路

```
清晰规约 → AI 辅助设计 → AI 执行编码 → 人工审查 → CI 验证
```

1. **前置投入**：需求写清楚，设计想清楚，AI 才能做对
2. **最小权限**：给 AI 刚好够用的权限，危险操作人工审批
3. **可回退**：每个 AI 任务前 git commit，出问题随时回滚
4. **透明协作**：PR 中注明 AI 生成的代码，关键逻辑必须人工 review
