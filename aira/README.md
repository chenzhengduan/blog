## 复刻承诺的范围

本包描述足够细的技术结构、接口定位、状态流转、配置字典、数据字段和重建步骤。它**不是可直接启动的完整项目镜像**：生产 Agent/Skill 正本和发布修订在数据库，Nacos 实值、租户业务数据、平台权限、网关和部署资源没有导出。

没有包含真实密钥、token、连接串或业务数据；源码中发现的硬编码凭证只说明位置与机制，不复制原值。本次也没有连接生产数据库、发送机器人消息、调用模型或做部署。缺项和可复刻验收方式在第 06 章逐项列明。
